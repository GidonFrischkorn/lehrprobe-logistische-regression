Jeder Test beruht auf einem Modell

Lineare Regression

\[Y_i \sim \mathcal{N}(\mu_i,\ \sigma^2), \quad \mu_i = \beta_0 + \beta_1 x_i\]

Binäre AV: Remission

\[Y_i \sim \mathcal{B}(1,\ \pi_i), \quad \pi_i = \ ?\]

Gleiche Struktur: eine Verteilung und ein Parameter, der von \(x\) abhängt.

Das Problem: der Wertebereich

\(\pi_i\) liegt zwischen 0 und 1, aber \(\beta_0 + \beta_1 x_i\) kann jeden Wert annehmen.

Wahrscheinlichkeit \(\pi\) 0 bis 1
Odds \(\dfrac{\pi}{1-\pi}\) 0 bis ∞
Log-Odds \(\ln\!\left(\dfrac{\pi}{1-\pi}\right)\) −∞ bis ∞

Denkpause: Wenn \(\pi = .8\), wie gross sind die Odds?

\(.8 / .2 = 4\): viermal so wahrscheinlich wie nicht. Kennen Sie aus dem Bayes-Beispiel (Prior-Odds).

Das logistische Regressionsmodell

\[Y_i \sim \mathcal{B}(1,\ \pi_i)\]

\[\pi_i = \ ?\]

\[\ln\!\left(\frac{\pi_i}{1-\pi_i}\right) = \beta_0 + \beta_1 x_i\]

Zurück zur Wahrscheinlichkeit, wie im Bayes-Beispiel:

\[\text{Odds}_i = e^{\text{Log-Odds}_i} = e^{\beta_0 + \beta_1 x_i}\]

\[ \pi_i = \frac{\text{Odds}_i}{1 + \text{Odds}_i} = \frac{e^{\beta_0 + \beta_1 x_i}}{1 + e^{\beta_0 + \beta_1 x_i}} \]

Kurve: \(\beta_0 = -3\), \(\beta_1 = 0.15\)

(6:10–7:10), 4 Klicks. Start: «pi_i = ?» wie auf Folie 5. [Klick] Logit-Gleichung ersetzt das Fragezeichen. Der lineare Teil bleibt: links steht jetzt logit(pi_i) statt mu_i. [Klick] Zurückrechnen, erster Schritt (blau): e hoch Log-Odds gibt die Odds. [Klick] Zweiter Schritt (blau): Odds/(1 + Odds) gibt die Wahrscheinlichkeit. Dieselbe Formel wie im Bayes-Beispiel. [Klick] Ergebnis: Die S-Kurve. Sie bleibt zwischen 0 und 1, egal wie viele Sitzungen.

Mitnehmen

  1. Jedes statistische Modell ist eine Verteilungsannahme: Normalverteilung für stetige, \(\mathcal{B}(1, \pi_i)\) für binäre AVs.
  2. Weil \(\pi_i\) zwischen 0 und 1 liegt, modellieren wir die Log-Odds von \(\pi_i\) als lineare Funktion von \(x\).
